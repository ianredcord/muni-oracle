# 三牌陣深度解說層 v3（2026-10-26，待確認後實作）

## 0. 問題

精簡版與完整版的每一段都是 35–95 字的「一句話」：位置短文說這張牌在這個位置的狀態，關係句與走向句說結構。它們能讀懂，但讀完的感覺是「所以呢？」——沒有解釋**為什麼這張牌在這個位置會這樣說、三支花精為什麼這樣搭、今天實際可以做什麼**。單張頁的深度來自六個區塊（象徵、榮格、花精光譜、三步、能量支持、系統對應），三牌陣把這些全部推到百科頁，所以淺。

## 1. 設計原則

- **深度不等於長**：每一段深度解說回答一個明確的問題，標題就是那個問題。
- **先用已核准的內容**：78 張牌各有約 700 字已審過的深度欄位（象徵、榮格、花精光譜、辨識、呼吸、香氣、日常練習、覺察）。第一層深度直接從這裡組，依位置重新編排，不寫新字。
- **新寫的只補結構缺口**：牌本身的深度已經有；缺的是「位置為什麼這樣讀」「走向怎麼用」「複方怎麼搭」這三種結構解說，這部分要新寫、走 lint、draft 送審。
- **三層遞進**：精簡（一分鐘）→ 完整（關係與複方）→ 深度（為什麼與怎麼做）。深度層在完整版底下逐段展開，不另開頁面；百科頁仍是最底層。

## 2. 深度層的區塊（在完整版對應位置下方，各自可展開）

### 2.1 每張牌下方：「深入這張牌」（來源：既有欄位，依位置選）

| 位置 | 問題（標題） | 來源欄位 | 字數 |
|---|---|---|---|
| 來處 | 這張牌帶著什麼來？ | step1Status（辨識）＋ flowerSpectrum | 約 150 |
| 來處 | 它的象徵在說什麼？ | symbolReading | 約 130 |
| 此刻 | 這張牌的核心訊息 | uprightMessage | 約 100 |
| 此刻 | 為什麼是這支花精？ | flowerSpectrum ＋ jungianAnalysis | 約 210 |
| 此刻 | 現在就能做的 | breathing（當下調節）＋ aromaGuide（香氣） | 約 100 |
| 去向 | 它的象徵在說什麼？ | symbolReading | 約 130 |
| 去向 | 如果往這裡走，可以練什麼？ | dailyPractice ＋ awarenessNote | 約 150 |

模式 C 改為：原型 → jungianAnalysis＋symbolReading；人格 → uprightMessage＋flowerSpectrum；情境 → step1Status＋dailyPractice。

每一段前加一行「位置導語」（新寫，固定句型，每位置 1 句、不依牌）：例如來處「這些是它一直帶在身上的東西，不是今天才出現的。」此刻「這張牌是今天的中心；下面是它的來歷，與現在就能做的事。」去向「去向不是預告，是如果你允許，可以往哪裡練。」

### 2.2 走向下方：「這個走向怎麼用」（新寫，6 型 × 2 變體，各 150–220 字，draft）

回答三個問題：這個走向在三張牌之間代表什麼結構／它常見的誤讀是什麼（例如回落不是退步）／今天可以怎麼對待它。條件式、不預測。

### 2.3 關係句下方：「兩張牌為什麼這樣接」（新寫，4 種元素關係 × 2 變體 ＋ 大牌/小牌 2 種 ＋ 同花色 1 種，各 100–160 字，draft）

解釋元素尊嚴（同／友／斥／中）在感受上像什麼，為什麼「相斥」不是壞事；大秘儀與小秘儀相鄰時層次怎麼讀；同花色時為什麼是同一個生活領域。

### 2.4 複方下方：「三支花精怎麼搭」（半組合：角色說明新寫 3 段＋每支花精用既有 flowerSpectrum）

- 主（此刻）：「今天的中心」為什麼由此刻這張牌決定；
- 釋放（來處）：為什麼來處的花精是用來放下的；
- 支持（去向）：為什麼去向的花精是扶一把而不是推。
各 80–120 字，draft；每列下方帶那支花精的 flowerSpectrum。

### 2.5 結尾前：「今天怎麼用這一局」（組合，不新寫）

把三張牌的實作欄位排成一天的順序：早上——此刻牌的呼吸法；白天——去向牌的日常練習；想到就做——此刻牌的香氣；晚上——來處牌的覺察方式。每項標出來源牌，讓使用者知道為什麼。

## 4. 資料與引擎

- 新增 `handoff/data/deep_text.v2.json`（walkthrough 導語、走向解說、關係解說、複方角色），schema v2（`text:{zh,en?}`、`status`、`trigger`），產生 `src/data/threeCard/deepText.ts`。
- 引擎不改選取：深度層依 state（arc、rel_12、rel_23、kinds、same_suit）直接查對應段落，同一 trigger 多變體時用 reading_id 做穩定選擇；不進 reading 紀錄的 selections（重播時用同樣規則，結果一致）。
- server action 回傳每張牌的深度欄位（symbolReading、jungianAnalysis、flowerSpectrum、step1Status、uprightMessage、breathing、aromaGuide、dailyPractice、awarenessNote）。
- 事件：展開深度層記 `opened_deep`（meta.section），與百科頁的 opened_deep 用 meta 區分。

## 5. 頁面

- 完整版每個區塊右下角「深入 ▾」；展開後顯示 2.1–2.5。
- 「全部展開」按鈕在三張牌總覽下方。
- 深度層文字用正文字級，標題用問句；長段落內用小標分段，不超過三段一組。
- 字數預算：完整版＋深度層全展開約 2,500–3,000 字；以可展開控制首屏。

## 6. 順序建議

1. 先做 2.1 與 2.5（不寫新字，一天內可上線），讓深度立刻出現。
2. 再寫 2.2 走向解說 12 段送審（最常被問「這什麼意思」的就是走向）。
3. 再寫 2.3 關係解說與 2.4 複方角色。
