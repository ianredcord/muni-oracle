# MUNI 全站旅程規劃

主軸：**回到自己，從一張牌開始。**

抽牟尼牌卡 → 聞牟尼香 → 貼 Fascia Point → 看筋膜觀察室 → 回到自己。

## 五個步驟

| 步驟 | 訪客在做什麼 | 入口 |
| --- | --- | --- |
| 抽牟尼牌卡 · 覺察當下 | 讀一句允許語，辨識當下的感受，選擇是否繼續探索。 | /draw |
| 聞牟尼香 · 片刻停留 | 認識牟尼香精油，透過香氣留一段覺察時間。 | /muni-scent |
| 貼 Fascia Point · 感受身體 | 認識筋膜貼，留意身體感受；依產品使用說明使用。 | /fascia-point |
| 看筋膜觀察室 · 理解結構 | 從想了解的部位開始，查看相關結構及圖層。 | /meridian-observatory |
| 回到自己 · 把覺察帶回日常 | 記下當下感受、做一個熟悉的動作，留下下次可以回看的記錄。 | /journal（銜接前需確認現有功能） |

## 全站如何串接

- 首頁：放完整旅程圖，主按鈕為「從一張牌開始」，五個入口都可自由選擇。
- 抽牌結果：在既有牌卡解讀之後，加入「給自己片刻停留」與牟尼香入口，以及「記下這一刻」的記錄入口。
- 牟尼香頁：說明精油與使用方式，再銜接「留意身體的感受」至 Fascia Point。
- Fascia Point 頁：銜接「看看你想了解的位置」至觀察室介紹頁；不可用抽到的牌決定貼用位置。
- 觀察室介紹頁：展示同一旅程，保留牌卡、精油、筋膜貼與工作台入口。
- 完成後：以簡短記錄收尾。若希望自動帶入牌卡、身體部位或跨裝置保存，另行評估資料流與會員功能。

訪客不必依序完成，也不必購買產品才能抽牌或探索。旅程表達品牌的連結，不表示牌卡可以診斷，也不表示產品會保證改善健康。

## 視覺

暖白、橄欖綠、金色細線，串起五個場景。採用網站既有牌卡、MUNI ONE 精油瓶及 Fascia Point 包裝作為生成參考。圖像為概念插畫，與工作台真實模型展示區別。
