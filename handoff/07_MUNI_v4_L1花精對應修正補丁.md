# MUNI v4 L1 花精對應修正補丁

對象：`muni-oracle` → `MUNI_78Cards_Content_v4.json` 與 `src/data/tarot.generated.ts`　版本 2026-10

---

## 一、問題

v4（2026-04-10）的 L1 原型層（22 大秘儀＋16 宮廷牌）中，Honeysuckle 忍冬出現在太陽與聖杯騎士、Crab Apple 野生酸蘋果出現在節制與寶劍國王；Hornbeam 角樹（權杖三）與 Pine 松樹（聖杯九）因此在 L1 沒有對應，`systemL2Echo` 為「—」。這違反「38 支單方在兩層各出現一次」的設計，也會讓三牌陣的雙層共振把兩張同層的牌誤判為共振。

追溯二月的 v3 對照：宮廷牌對應（聖杯騎士＝Honeysuckle、寶劍國王＝Crab Apple）當時就存在；重複是四月大秘儀重排（太陽改 Honeysuckle、節制改 Crab Apple 等六張連鎖調整）之後，宮廷牌沒有跟著調整造成的。

## 二、修正原則與選擇

| 選項 | 內容 | 代價 | 採用 |
|---|---|---|---|
| A 改大秘儀 | 太陽 → Hornbeam、節制 → Pine | 兩張大秘儀的 11 維度內容全部重寫；太陽離開「對當下興趣不足」群組，破壞愚者之旅七群組結構 | 否 |
| B 回復 v3 大秘儀 | 六張大秘儀連鎖改回 | 推翻四月已鎖定、已寫好內容的重排 | 否 |
| C 改宮廷牌 | 聖杯騎士 → Hornbeam、寶劍國王 → Pine | 兩張宮廷牌的花精相關欄位重寫；大秘儀與七群組結構不動 | 是 |

C 的契合度：聖杯騎士是「心已在路上、身體停在起點」的浪漫騎士，Hornbeam 處理的正是有方向卻提不起勁出發的遲疑；寶劍國王是最高法官，Pine 處理的是把判決轉向自己、永遠無法結案的自責——v4 寶劍國王的 `reversedReminder` 原本就寫到「用完美主義懲罰自己」，Pine 比 Crab Apple 更貼近這句。Pine 與 Crab Apple 同屬「沮喪絕望」群組，寶劍國王的群組不變；聖杯騎士從「對當下興趣不足」改為「不確定」群組。

### 3.3 聖杯騎士 × 角樹 Hornbeam：內容欄位重寫

保留 `symbolReading`、`uprightMessage`（與花精無關）；以下 11 個欄位為新稿。

- `keywords`：浪漫、追尋、理想化、感性使者、啟程前的遲疑
- `step1Status`：你可能心裡已經很清楚想去哪裡——那個人、那件事、那段旅程——但每天早上醒來，都覺得還沒有力氣出發。不是不想，是提不起勁，像週一早晨的那種疲倦。
- `step2Allow`：我允許自己在還沒準備好的感覺裡，先踏出一小步。
- `step3Body`：留意你的大腿前側與膝蓋——想出發卻遲遲沒動時，這裡常常是沉的。站起來，原地輕輕抬膝十次，感受腿重新記起「走」的感覺。
- `breathing`：吸氣四拍想像清晨的涼意灌進胸口，吐氣四拍把「等一下再說」輕輕放掉，第三次吐氣時讓肩膀落下，重複六次，直到身體比腦袋先想動。
- `aromaGuide`：取 MUNI ONE 精油塗抹於太陽穴與後頸，像是為自己開一扇窗——不是推你出門，而是讓今天的空氣先進來，等你自然想跟著它走。
- `dailyPractice`：今天選一件你已經想很久、卻一直沒開始的小事，只做前五分鐘——寫第一句、打第一通電話、走到門口。五分鐘後可以停，但多數時候，馬已經在走了。
- `awarenessNote`：覺察像是看一匹停在河邊的馬——牠不是不想過河，只是在等水面安靜一點。你不必催牠，只要注意到牠的耳朵已經轉向對岸，那就是出發的前兆。
- `flowerSpectrum`：當你處於心裡有方向、身體卻提不起勁，每個早晨都像週一，把想做的事一天天往後推的狀態時，角樹花精陪伴你找回出發前的那一點新鮮，讓第一步變得不那麼重。
- `jungianAnalysis`：浪漫騎士的原型帶著對美與愛的永恆追尋，他是詩人也是使者。陰影面是角樹的遲疑——心已在路上，身體卻一直停在起點，用「還沒準備好」把旅程無限延後。個體化的邀請是明白：騎士不是在完全準備好時出發，而是在出發後才慢慢準備好。
- `reversedReminder`：你是否已經在心裡走過那段路很多次，現實中卻一步都還沒踏出？當「明天再開始」變成每天的句子，也許不是你不夠想要，而是你太久沒有讓身體先動。聖杯端得再穩，馬也要走。

### 3.4 寶劍國王 × 松樹 Pine：內容欄位重寫

保留 `symbolReading`、`uprightMessage`（與花精無關）；以下 11 個欄位為新稿。

- `keywords`：理性、公正、權威判斷、清晰思維、對自己最嚴的法官
- `step1Status`：你可能正在為一件已經過去的事反覆自責——即使別人都說不是你的錯。你對自己的判決總比對別人嚴，一句「我早該想到」在心裡重複了很多次。
- `step2Allow`：我允許自己卸下不屬於我的責任，判決可以結案了。
- `step3Body`：留意你的上背與兩側肩胛之間——自責時那裡常常是繃緊往內收的。把雙手背到身後輕輕互握，肩胛往中間靠，停三秒再放開，像是替自己解開一副無形的枷鎖。
- `breathing`：吸氣四拍，吐氣六拍，吐氣時在心裡說一次「這一件，可以放了」。重複七次，每一次都讓吐氣比吸氣長一點——長一點的吐氣，是身體版的赦免。
- `aromaGuide`：取 MUNI ONE 精油塗抹於手腕內側與胸口，雙手交疊放在胸前片刻。這個動作不是審判也不是辯護，是把法官的位置暫時讓給一個願意對你溫柔的人。
- `dailyPractice`：今天找出一件你一直在心裡怪自己的小事，把它寫成一句話，然後在後面寫：「我當時已經用我知道的方式做了。」讀一遍，把紙摺起來。案件結案不需要別人簽字。
- `awarenessNote`：覺察像是坐在法庭的旁聽席——你看著那個法官一次次重審同一個案子，而被告每次都是你。你不需要推翻判決，只要注意到：法官和被告，其實是同一個人，他可以選擇休庭。
- `flowerSpectrum`：當你處於過度自責、為別人的錯誤攬下責任、無論做得多好都覺得「還不夠」的狀態時，松樹花精陪伴你從自我審判中退庭，看見你已經盡力，也值得被自己原諒。
- `jungianAnalysis`：最高法官的原型代表心智發展的頂峰，他能用思維的光照亮最黑暗的角落。陰影面是松樹的自我審判——把清明的判斷力全部轉向內在，變成一個永遠無法結案的法庭。個體化的終極挑戰是把公正也用在自己身上：一個真正公正的法官，不會對自己判得比別人重。
- `reversedReminder`：你是否正對自己進行一場永遠達不到標準的審判？那些「我早該、我不該、都是我」的念頭，可能不是在追求卓越，而是在用罪惡感懲罰自己。公正的第一條，是對自己也公正。

## 四、重新產出的位置短文（6 段）


### 聖杯騎士（角樹 Hornbeam）

- 來處：你一路心裡有方向，身體卻一直停在起點。那段旅程在腦中走過很多次，現實裡還沒踏出第一步。
- 此刻：此刻可以先動一小步——角樹（Hornbeam）陪你讓身體比腦袋先出發。允許句：我允許自己在還沒準備好的感覺裡，先踏出一小步。
- 去向：如果你允許自己在還沒準備好時先踏出一步，追尋會從想像變成在路上：馬一走，風景就會來。

### 寶劍國王（松樹 Pine）

- 來處：你一路對自己判得最重。一件過去的事反覆重審，「我早該想到」在心裡說了很多次，別人怎麼說都沒用。
- 此刻：此刻判決可以結案——松樹（Pine）陪你把法官的位置暫時讓出來。允許句：我允許自己卸下不屬於我的責任，判決可以結案了。
- 去向：如果你允許卸下不屬於你的責任，清晰會回到正確的方向：切開問題，而不是切向自己。


其餘 228 段不受影響。234 段重新通過語氣檢查（無禁用詞、去向含「如果」「允許」、此刻含花精名、無重複）。

## 五、三牌引擎同步調整

- 共振判定：兩張同花精的牌必須分屬 L1 與 L2 才算共振，急救花精不參與。修正前「太陽 → 權杖十 → 聖杯騎士」會誤判為共振，現已不觸發。
- 複方去重：共振命中時同支花精自動合併，複方縮為 2 支，並由 `resonance` 槽的句子說明。
- 以上已更新在 `muni_assemble_reference.py`；位置短文與組裝示範改讀 `cards_v4_patched.json`。

## 六、套用方式

1. 以 `cards_v4_patch_diff.json`（40 筆 card_id／field／before／after）為準，套用到 `MUNI_78Cards_Content_v4.json`，版本號建議升為 v4.1。
2. 重新產生 `tarot.generated.ts`；英文版 `tarot.en.generated.ts` 的聖杯騎士與寶劍國王需同步翻譯。
3. 兩張牌的牌面圖若有描繪花精植物（忍冬、野生酸蘋果），需依角樹與松樹重新生成；若牌面未畫花精植物則不必。
4. 知識殿堂若有引用「忍冬／野生酸蘋果」的其他維度文字（如奇經、煉金階段），請一併檢索替換。
