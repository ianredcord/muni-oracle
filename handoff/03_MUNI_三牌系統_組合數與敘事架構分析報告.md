# MUNI 三牌系統：組合數與敘事架構分析報告

munione.co 塔羅 V2「來處・此刻・去向」牌陣
版本：2026-10-25 初稿

---

## 一、報告摘要

- 78 張牌抽 3 張，若不分位置是 76,076 種組合；分「來處・此刻・去向」三個位置後是 456,456 種排列；若再納入正逆位則為 3,651,648 種。常被引用的「76 萬」其實是 76,076（7.6 萬）的誤讀，真正對產品有意義的數字是有位置的 456,456。
- 這 45.6 萬種排列不需要逐一撰寫。只要 234 段位置短文加上約 140 段規則模板，每一種排列都能由「3 段位置文 + 2 個相鄰關係 + 1 個整列結構 + 1 條敘事弧 + 合成規則」現場組裝，且任兩種排列產出的文字必然不同。
- 窮舉全部 456,456 種排列後，得到各規則狀態的真實分布：元素關係四類幾乎均分（各約 25%）；大秘儀 0／1／2／3 張分別佔 36%／45%／17%／2%；同一支花精雙層共振只佔 3.8%；三張皆宮廷牌僅 0.74%。這些比例決定了每一類模板該寫幾個變體、哪些是稀有例外。
- 既有敘事弧規則（推進／重複／化解／斷裂）會讓 54% 的排列落入「無弧線」預設；本報告提出修訂版（六型），把預設狀態壓到 16%，狀態空間從 520 擴到 716 個實際可達狀態。
- 權重控制的核心是「決定性種子 + 加權變體 + 語氣鎖」：同一個人同一天抽到同一組牌永遠得到同一篇文字，不同人或不同日期則在同一規則狀態下輪替變體。每槽 2 個變體時表面變化量為 1,460 萬篇，3 個變體時為 1.1 億篇，而撰寫量僅從 374 段增至約 650 段。

## 二、組合數學：真實變化量在哪裡

### 2.1 四個層次的數字

| 層次 | 計算式 | 數量 | 對應產品情境 |
|---|---|---|---|
| 無序組合（三張牌是哪三張） | \(\binom{78}{3} = \dfrac{78 \times 77 \times 76}{6}\) | 76,076 | 不分位置的「三張牌集合」 |
| 有序排列（哪張在哪個位置） | \(P(78,3) = 78 \times 77 \times 76\) | 456,456 | 來處・此刻・去向（模式 A／B） |
| 有序排列 × 正逆位 | \(456{,}456 \times 2^3\) | 3,651,648 | V3 若開放逆位視覺化 |
| 三面鏡分池（模式 C） | \(22 \times 16 \times 40\) | 14,080 | 原型・人格・情境各抽一張 |

補充兩個常用參考值：任兩張牌的有序配對為 \(78 \times 77 = 6{,}006\) 種，無序為 3,003 種；這是「關係層」規則需要覆蓋的全部相鄰情形。

### 2.2 為什麼「有序」才是真實變化量

同樣三張牌「五號聖杯、愚者、星星」，放成「五號聖杯 → 愚者 → 星星」與「星星 → 愚者 → 五號聖杯」，在 MUNI 的框架下是兩個完全不同的故事：前者是帶著失落走向平靜信任，後者是曾經擁有的平靜如今感到失落。每個無序組合平均展開成 \(3! = 6\) 種排列，因此 \(76{,}076 \times 6 = 456{,}456\)。位置本身就是意義的一部分，所以產品真正要覆蓋的是 456,456 種，而不是 76,076 種。

### 2.3 逆位的數學代價

逆位讓排列數乘以 8。但先前已決定 V2 不做視覺逆位，而是把「堵塞／內化」的概念放進知識殿堂的維度。從組合數學看這個決定也合理：逆位會讓每一段位置短文需要「正／逆」兩個版本（234 → 468 段），關係層與結構層規則也要處理「逆位是否影響元素尊嚴」的分歧，撰寫量翻倍，但使用者在主畫面感受到的差異很小。

## 三、窮舉統計：456,456 種排列的真實分布

以下數字由程式窮舉全部有序排列計算，牌庫設定依既有 MUNI 架構：22 張大秘儀（元素依黃金黎明占星對應）、16 張宮廷牌、40 張數字牌；L1 = 大秘儀 + 宮廷牌共 38 張對應 38 支花精，L2 = 40 張數字牌對應 38 支花精 + 2 張急救。整合型牌定義為節制、星星、世界、四張 10、四張 King，共 11 張。

### 3.1 元素尊嚴：相鄰兩張牌的關係

| 關係 | 定義 | 出現比例（每個相鄰對） |
|---|---|---|
| 同元素（same） | 火火、水水、風風、土土 | 24.1% |
| 友好（friendly） | 火＋風、水＋土 | 25.3% |
| 對立（hostile） | 火＋水、風＋土 | 25.3% |
| 中性（neutral） | 火＋土、風＋水 | 25.3% |

四類幾乎均分，表示四類模板的曝光頻率相同，每類變體數量應一致，不需偏重。

兩個相鄰對（來處－此刻、此刻－去向）的 16 種組合中，每一種落在 5.6%～6.5% 之間，分布極為平均。「兩側皆對立」（傳統上忽略側牌、只讀中央）佔 6.2%，大約每 16 次抽牌出現一次，值得寫成專屬句型而不是套用通用模板。

### 3.2 大秘儀比例

| 大秘儀張數 | 排列數 | 比例 | 結構句定位 |
|---|---|---|---|
| 0 張 | 166,320 | 36.4% | 「課題在日常裡，具體可調整」 |
| 1 張 | 203,280 | 44.5% | 「底下有一條深層的河流」 |
| 2 張 | 77,616 | 17.0% | 「這段時期有分量」 |
| 3 張 | 9,240 | 2.0% | 「這是一個人生章節」 |

超過八成的抽牌是 0 或 1 張大秘儀，這兩句結構句是使用者最常讀到的，各需至少 3 個變體；3 張大秘儀每 50 次才出現一次，1 個精心寫的版本就夠，反而能保有「稀有感」。

### 3.3 宮廷牌與 MBTI 張力

| 宮廷牌張數 | 比例 |
|---|---|
| 0 張 | 49.7% |
| 1 張 | 39.8% |
| 2 張 | 9.8% |
| 3 張 | 0.74% |

約一半的抽牌會觸發「本命 vs 抽到」的 MBTI 張力句。三張全宮廷每 135 次出現一次，屬於需要專屬例外文案的情形。

### 3.4 花精雙層共振

同一支花精在 L1 與 L2 同時出現（例如愚者＝Clematis 與某張數字牌＝Clematis）的機率只有 3.8%，約每 26 次抽牌一次；三張同一支花精在數學上不可能（每支花精只在兩層各出現一次）。這表示「雙層共振加權、複方縮為 2 支」是一個真正稀有的事件，文案可以寫得鄭重一點，不會因頻繁出現而貶值。

### 3.5 敘事弧：既有規則的問題與修訂

既有四型規則（斷裂 → 化解 → 重複 → 推進，依優先序判定）的實際分布：

| 弧型 | 既有規則比例 |
|---|---|
| 推進型 | 15.2% |
| 重複型 | 10.4% |
| 化解型 | 13.1% |
| 斷裂型 | 7.1% |
| 未命中（無弧線） | 54.1% |

超過一半的排列沒有弧線可說，整合頁會少掉最重要的那一段。問題出在「推進型」只比較同類牌的編號，大秘儀對數字牌、數字牌對宮廷牌都無法判定。修訂版把每張牌的位階正規化到 0～1（大秘儀 編號/21、小秘儀 (位階−1)/13），再用差值判定：

| 弧型 | 修訂規則 | 比例 | 過渡句核心 |
|---|---|---|---|
| 斷裂型 | 來處與去向元素對立，且此刻為大秘儀 | 7.1% | 「過去和方向在拉扯，此刻這張大牌正是轉折點」 |
| 化解型 | 去向為整合型牌 | 13.1% | 「這條線正在收攏」 |
| 重複型 | 來處與去向同花色，或同為大秘儀且同元素 | 11.9% | 「同一個模式出現兩次——此刻正是改寫的位置」 |
| 推進型 | 去向位階 − 來處位階 ≥ 0.15 | 22.5% | 「能量在往前走」 |
| 回落型（新增） | 去向位階 − 來處位階 ≤ −0.15 | 29.1% | 「不是退步，是回到更根本的地方重新開始」 |
| 持平型（新增） | 其餘 | 16.4% | 「來處與去向站在同一個高度，重點在此刻怎麼轉身」 |

修訂後沒有「未命中」，每一次抽牌都有一段弧線。回落型是最常見的弧線（29%），這段文案的語氣特別重要：它最容易被讀成「變差」，必須寫成「向下扎根」而非「下滑」。

### 3.6 狀態空間的大小

把六個判定維度合起來看——相鄰關係 1（4 類）× 相鄰關係 2（4 類）× 敘事弧（6 型）× 大秘儀張數（4 級）× 是否有宮廷牌（2）× 是否雙層共振（2）——理論上限是 \(4 \times 4 \times 6 \times 4 \times 2 \times 2 = 1{,}536\) 個狀態，窮舉後實際可達 716 個。也就是說：

- 456,456 種排列，被規則層收斂成 716 個「結構狀態」；
- 每個結構狀態平均對應 637 種排列；
- 每一種排列再由各自的 3 段位置短文拉開差異。

這就是「幾百段短文撐起幾十萬種結果」的數學結構：規則層負責收斂，位置層負責發散。

## 四、從組合到短文：對應關係與壓縮比

### 4.1 一次抽牌的組裝路徑

任何一組「來處・此刻・去向」都走同一條路徑：

1. 查表：取來處牌的「來處」段、此刻牌的「此刻」段、去向牌的「去向」段（3 段，來自 234 段庫）。
2. 判定：相鄰關係 ×2、敘事弧 ×1、大秘儀張數 ×1、宮廷牌 ×1、雙層共振 ×1（6 個狀態值）。
3. 選模板：依狀態值從規則表取出對應槽位的模板句（約 5～6 段）。
4. 合成：依合成規則產出花精複方（主／釋放／支持）、合成允許句、一個身體練習。
5. 收尾：固定結語「三張牌是三面鏡子，不是三個判決。」

### 4.2 為何任兩種排列的輸出必然不同

因為 234 段位置短文每一段都是「特定牌 × 特定位置」唯一的。兩種排列只要有任一位置的牌不同，該位置的短文就不同，整篇輸出就不同。因此即使規則層只有 716 個狀態，456,456 種排列仍對應 456,456 篇不同的文字——規則層負責的是「語氣與結構一致」，不是「製造差異」。

### 4.3 壓縮比

| 項目 | 數量 |
|---|---|
| 需覆蓋的排列（模式 A／B） | 456,456 |
| 需覆蓋的排列（模式 C） | 14,080 |
| 位置短文 | 234 |
| 規則模板（基礎版，各槽 1 變體） | 約 140 |
| 撰寫總量 | 約 374 段 |
| 壓縮比 | 約 1,220 : 1 |

這個比值的意義是：每寫一段文字，平均會在 1,220 種不同的抽牌結果中被重複使用。這也是為什麼模板句必須寫成「連接詞」而不是「結論」——它會被放進一千多種不同的脈絡裡。

### 4.4 加入變體後的表面變化量

若規則層每個槽位（相鄰關係 ×2、敘事弧、大秘儀結構、收尾）各寫 \(v\) 個等價變體：

| 每槽變體數 \(v\) | 每種排列可能的輸出數 \(v^5\) | 表面變化總量 | 規則模板撰寫量 |
|---|---|---|---|
| 1 | 1 | 456,456 | 約 140 段 |
| 2 | 32 | 約 1,460 萬 | 約 280 段 |
| 3 | 243 | 約 1.1 億 | 約 420 段 |

從 1 變體到 3 變體，撰寫量增加 280 段，表面變化量增加 242 倍。這是投入報酬率最高的一段：建議常見狀態（0／1 張大秘儀、推進型、回落型、四類元素關係）寫 3 個變體，稀有狀態（3 張大秘儀、三宮廷、雙層共振）寫 1 個。

### 5.3 狀態向量：規則層的輸入

每次抽牌先算出一個六維狀態向量，之後所有模板選取都只看這個向量，不再回頭看牌：

```
state = {
  rel_12:      same | friendly | hostile | neutral
  rel_23:      same | friendly | hostile | neutral
  arc:         rupture | resolve | repeat | advance | settle | hold
  major_count: 0 | 1 | 2 | 3
  court_count: 0 | 1 | 2 | 3
  resonance:   none | pair          （同支花精出現兩次）
  flags:       both_sides_hostile | all_court | all_major | ...
}
```

判定順序必須固定寫進規則表（例如 arc 的優先序：rupture → resolve → repeat → advance／settle → hold），否則同一組牌可能因程式版本而落入不同狀態。

### 5.4 `slot_templates`：模板句的統一格式

```
template_id      ARC_SETTLE_02
slot             arc | rel_12 | rel_23 | structure | court | resonance | closing
trigger          {"arc":"settle"}                      （狀態條件，可多鍵）
exclude          {"flags":["all_major"]}               （互斥條件）
text             「這不是退步——是回到更根本的地方，把地基重新踩實。」
weight           3                                     （抽樣權重）
tone_tags        [permissive, grounding]
length_chars     38
requires_before  rel_12                                 （槽位順序依賴，可選）
version          2026-10
```

同一個 `slot` + 同一個 `trigger` 下有多筆就是變體；`weight` 決定被選到的相對機率，`exclude` 處理「這個變體在特定旗標下不適用」。

### 5.5 組裝順序（槽位序列）

整合頁的段落順序固定，每個槽位最多填一句：

```
1. structure   大秘儀張數結構句（定調這次抽牌的「重量」）
2. origin      來處牌位置短文
3. rel_12      來處→此刻 關係句（連接詞性質）
4. now         此刻牌位置短文（含允許句與主花精）
5. rel_23      此刻→去向 關係句
6. direction   去向牌位置短文（條件句「如果…就會…」）
7. arc         敘事弧過渡句（整列總結）
8. court       宮廷牌 MBTI 張力句（有宮廷牌且使用者有填 MBTI 時）
9. resonance   雙層共振句（resonance = pair 時）
10. synthesis  花精複方 + 合成允許句 + 一個身體練習
11. closing    固定結語
```

8、9 兩槽是條件槽，不觸發時整段省略而非留白；其餘槽位必填。全文字數預算約 380～480 字，由 `tone_lexicon` 的 `length_budget` 控制，超出時優先裁減 structure 與 arc 的變體為短版。

### 5.6 權重控制：如何讓變化「千變萬化但可重現」

**決定性種子。** 變體選取不用純隨機，而用 `seed = hash(user_id, date, card_1, card_2, card_3)`。效果是：同一個人同一天重抽同一組牌，看到的文字一字不差（避免「怎麼又變了」的不信任感）；不同人、不同日抽到同一組牌，則在同一狀態下看到不同變體。

**加權抽樣。** 每個槽位依 `weight` 做加權選取。權重有三個用途：
- 新寫的變體先給低權重（1），觀察一週後若無品質問題再調到正常（3）；
- 季節或活動期間可臨時調高某些變體（例如年初調高 advance 型的「啟程」語氣）；
- 從使用者行為回饋（展開深度解析、點擊花精）反推哪些變體效果好，逐步調整。

**互斥與必選。** `exclude` 處理語氣衝突（例如 all_major 旗標下不使用「這很日常」類變體）；`exceptions` 表的整段文案若命中，直接覆蓋槽位 1～9，只保留 synthesis 與 closing。

**反重複。** 同一使用者 30 天內看過的 `template_id` 記錄下來，選取時對已看過的變體權重乘以 0.3，讓常抽牌的使用者更少遇到重複句。

### 5.7 語氣鎖：一致性的三道防線

規則表之外，語氣一致靠三個機制：

| 防線 | 機制 | 範例 |
|---|---|---|
| 詞彙層 | `tone_lexicon` 禁用詞與替代詞表，入庫時自動檢查 | 禁「你將會」「注定」「命中」「警告」；去向槽強制含「如果」或「允許」 |
| 句型層 | 每個槽位有固定句型骨架，變體只能在骨架內變化 | 去向段：條件句；關係句：以「——」或「而」開頭的連接句；弧線句：先否定宿命再給方向 |
| 結構層 | 槽位序列固定，條件槽只省略不改位 | 使用者每次讀到的段落節奏相同，差異只在內容 |

模板入庫流程建議是：Google Sheet 撰寫 → 批次生成變體 → 自動跑詞彙層檢查 → 人工審句型層 → 給低權重上線。

## 八、限制與風險

- 比例數字建立在既定的牌庫設定上（大秘儀元素依黃金黎明占星對應、整合型牌 11 張）。若修改這些定義，分布會變，但窮舉程式可以直接重跑。
- 修訂版敘事弧的門檻值 0.15 是為了讓六型分布合理而設定的參數，不是塔羅實務的既定規範；建議上線後對照使用者的「這段準嗎」回饋再微調。
- 壓縮比高意味著每一句模板都會被放進上千種脈絡裡，單一句寫壞的影響面很大。入庫前的語氣檢查比變體數量更重要。
- 決定性種子能保證可重現，但也表示若某個變體有錯字，同一位使用者會重複看到；修正後需清除該使用者當天的快取。
- 本報告處理的是結構與數學，不涉及牌義或花精對應的效度；所有「允許句」「身體練習」仍屬陪伴式內容，不是療效宣稱。
